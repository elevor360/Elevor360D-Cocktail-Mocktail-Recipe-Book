Elevor360D Cocktail & Mocktail Recipe Book V1

50 individually written drinks: 30 mocktails and 20 cocktails.
Includes ingredient/portion scaling, search, favourites, shopping lists, personal
recipes, meal planner, large graphic timer, backup and restore, offline PWA and
existing rotating advertising configuration.

Upload the website files and advertising folder to your GitHub Pages repository.
Keep Elevor360D_Drinks_Recipe_Manager_V1.html on your own computer (do not
publish the manager). Import recipes.json into the manager to edit recipes,
then export and replace recipes.json on GitHub. Update the service worker cache
version when publishing changes to recipes.

Adult alcoholic drinks are identified as Cocktails; Mocktails are alcohol-free
formulations, but check mixer labels for strict zero-alcohol needs.
Recipes have not been independently tested.
